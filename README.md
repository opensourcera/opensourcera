## About

I build and release open source software across a wide range: from tiny microcontroller code to desktop tools for Windows, keyboard utilities and financial tools.

The approach is the same every time. Take one simple idea, implement it cleanly, release it immediately, and improve it in the open.

## Principles

| | |
|---|---|
| **Freedom first** | Software should be readable, modifiable and shareable by anyone who uses it. |
| **Simple beats clever** | One clear idea, done well, is worth more than a long feature list. |
| **Instant release** | Ship the working idea today. Refine it in public, with the people who use it. |
| **Small is powerful** | A few hundred lines on a microcontroller is real software and deserves real care. |
| **Tools should disappear** | The best tool gets out of the way and lets you do the work. |

## Featured projects

### RainaCore

<a href="https://github.com/opensourcera/RainaCore"><img src="https://raw.githubusercontent.com/opensourcera/RainaCore/main/docs/screenshots/map.jpg" alt="RainaCore map screen on the Seeed Wio Tracker L2 Pro" width="480"></a>

**RainaCore** is open-source touch firmware for the Seeed Wio Tracker L2 Pro, with no phone needed: chat, contacts, repeaters, channels and an offline map on its 320×240 screen. Compatible with MeshCore, but not connected to MeshCore development. Now in beta.

[Source](https://github.com/opensourcera/RainaCore) · [Install](https://github.com/opensourcera/RainaCore#install) · [Issues](https://github.com/opensourcera/RainaCore/issues)

### SleepCYD

<a href="https://github.com/opensourcera/SleepCYD"><img src="https://raw.githubusercontent.com/opensourcera/SleepCYD/main/docs/videos/sleepcyd-demo.gif" alt="SleepCYD demo on the Cheap Yellow Display" width="480"></a>

**SleepCYD** turns a 10 dollar ESP32 touch-screen board, the Cheap Yellow Display, into a pocket sleep analyzer for the WatchPAT ONE sensor. It records the night over Bluetooth to a microSD card, analyses it on the board in the morning, and shows the report on its own screen, on a phone through a QR code, or on a Nidra site. No PC, no phone app, no cloud account.

[Source](https://github.com/opensourcera/SleepCYD) · [Demo video, MP4](https://github.com/opensourcera/SleepCYD/raw/main/docs/videos/sleepcyd-demo.mp4) · [Issues](https://github.com/opensourcera/SleepCYD/issues)

### Raisin

<a href="https://github.com/opensourcera/raisin"><img src="https://github-readme-stats.vercel.app/api/pin/?username=opensourcera&repo=raisin&theme=default&hide_border=true" alt="Raisin repository card"/></a>

**Raisin** is a system-wide keyboard tool for Windows. It intercepts keystrokes at the OS level and rewrites them for any application, with no input method editor and no per-application setup. Built on .NET 8 with a lock-free processing pipeline, a plugin SDK and a 60,000 word dictionary. MIT licensed.

[Source](https://github.com/opensourcera/raisin) · [Download](https://www.unibijoy.com) · [Issues](https://github.com/opensourcera/raisin/issues)
