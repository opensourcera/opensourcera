## 🧭 About me

```text
🛠️  I build lightweight, zero-config developer and productivity tools for Windows
🍇  Creator of Raisin — a system-wide Unicode Bangla keyboard (no IME, no setup, just type)
🌐  Everything I ship is MIT licensed and open to contributors
🎯  Obsessed with low latency, clean architecture, and tools that simply work
```

- 🔭 **Currently working on:** [Raisin](https://github.com/opensourcera/raisin) · v1.7 beta · Avro Phonetic, UniBijoy and Jatiya layouts, AI spell & grammar checker, plugin SDK
- 🌱 **Learning:** .NET 8 performance tuning, lock-free pipelines, Win32 input hooks
- 🤝 **Open to:** collaborations on Bangla language tech, Windows tooling and open source utilities
- 💬 **Ask me about:** keyboard hooks, Unicode text input, shipping desktop apps on Windows

Notepad, Word, Chrome, VS Code, WhatsApp — with no IME and no per-app configuration.
